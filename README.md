# E-Food
Frontend prototype using Next.js App Router, React, TypeScript, Motion, Lenis, Zustand, Lucide and responsive CSS. Tailwind and GSAP are listed for future development but are not used in this implementation. No backend or payments. Food images and fonts are loaded externally; example data is illustrative. Pinterest short URL could not be opened, so visual direction is provisional.

Run `npm install` then `npm run dev` and open http://localhost:3000. Production: `npm run build` and `npm start`. Deploy to Vercel by importing the project repository.

## Generated food assets
Place generated transparent WebP files in public/food using product slugs as filenames. Missing assets use a neutral placeholder; no archived food photos are loaded. Generated photos are illustrative.
